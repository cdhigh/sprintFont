Text-IO interface


Sprint-Layout is able to export elements as a text file or import elements from a text file. These text files is used as an interface for competent programmers.


To Export elements, select Text-IO: Export elements... from the Extras menu.

Sprint-Layout then generates a text file with all the elements of the current layout.

If you want to export only certain elements of the layout, then select these elements just before you call the export command.


To Import elements, select Text-IO: Import elements... from the Extras menu.

Now you can select the desired text file and Sprint-Layout will import and generate all elements it contains.

The imported elements will "stick" on the mouse, and with one click you can place them now.


The format of Text-IO files


● A Text-IO file is an ordinary ASCII file. All elements are described in a simple line.

● Each line describes a complete element, beginning with the element-type.
Then comes the relevant parameters which describe the element-type (separated by commas).
At the end, there is always a semicolon and a RETURN.

● The order of the parameters does not matter, only the element type must always be at the beginning of the line.

● Spaces within a line are redundant, since they can be, but need not.

● Not case sensitive



Numeric format


● The unit of each value is either in millimeter or degree

● Angels in degree values are sometimes multiplied with the factor 100 or 1000 (see description)

● All millimeter values are multiplied with the factor 10000
A width of 0,6 mm appears as 6000

● All coordinate values have their origin in the top/left edge, and they count up to bottom/right
All coordinate values are in the X / Y format and are also defined in millimeters * 10000
A coordinate of X=12,08 mm / Y=21,2 mm appears as 120800 / 212000



Layer numbers


The layer of an element is specified with: LAYER=x

Where x is a number between 1..7:


1 = C1        (Copper top)

2 = S1        (Silkscreen top)

3 = C2        (Copper bottom)

4 = S2        (Silkscreen bottom)

5 = I1        (Inner copper layer 1)

6 = I2        (Inner copper layer 2)

7 = O        (Outline)

TRACK


Necessary parameters

TRACK

Keyword, must always be at the lines beginning

LAYER=3

Layer of the track

WIDTH=4600

Width of the track (mm*10000)

P0=1489707 / 561742

1. Point of the track (mm*10000)

P1=1489707 / 568092

2. Point of the track (mm*10000)

...

...



Optional parameters

CLEAR=6000

Distance to the automatic ground-plane (if used), default=4000

CUTOUT=true

Cutout-element (if automatic ground-plane is used), default=false

SOLDERMASK=true

Soldermask, default=false

FLATSTART=true

Track-start is flat, default=false

FLATEND=true

Track-end is flat, default=false

NAME=|text|

The text must be framed with the pipe character "|" (ASCII 124)



Example:

TRACK, LAYER=1, WIDTH=4600, P0=150000 / 250000, P1=150000 / 450000, P2=250000 / 450000;
TRACK, LAYER=3, WIDTH=8000, CLEAR=0, P0=150000 / 250000, P1=150000 / 450000, P2=250000 / 450000, P3=250000 / 650000, NAME=|ground|;




PAD


Necessary parameters

PAD

Keyword, must always be at the lines beginning

LAYER=3

Layer of the pad

POS=120000 / 240000

Center of the pad (mm*10000)

SIZE=16000

Diameter of the pad (mm*10000)

DRILL=8000

Diameter of the drilling (mm*10000)

FORM=1

Shape of the pad

1 = round

2 = octagon

3 = square

4 = round, horizontal

5 = octagon, horizontal

6 = rectangle, horizontal

7 = round, vertical

8 = octagon, vertical

9 = rectangle, vertical



Optional parameters

CLEAR=6000

Distance to the automatic ground-plane (if used), default=4000

SOLDERMASK=true

Soldermask, default=true

ROTATION=4500

Rotation angle (in °(deg) *100), default=0

VIA=true

Pad is a via, default=false

THERMAL=true

Pad is a thermal-pad (on the automatic ground-plane), default=false

THERMAL_TRACKS_WIDTH=80

Width of the thermal-bridges in % (50..300), default=100

Width=Pad-diameter / 3 * (THERMAL_TRACKS_WIDTH / 100)

THERMAL_TRACKS_INDIVIDUAL=true

Thermal-pad-bridges are defined individual for each layer, default=false

THERMAL_TRACKS=(32-bit-integer)

Thermal-pad-bridges 4 bytes à 8 bit on/off

(Low Byte=) C1 + C2 +I1 +I2 (=High Byte)

Each byte 8 bridges (bits), beginning at 12 o'clock, clockwise

PAD_ID=23

The PAD_ID is a unique ID for this pad

This ID is important for possibly defined connections (rubberbands), see next parameter CON

CON0=5

CON (connect) defines a connection from this pad to the pad with the given PAD_ID. It is possible to define several connections, separated by commas. The index x of the CONx parameter has to be started with 0 (zero) and has to be numbered consecutively.

NAME=|text|

The text must be framed with the pipe character "|" (ASCII 124)



Example:

PAD, LAYER=3, FORM=1, POS=88900 / 85600, SIZE=16000, DRILL=8000;
PAD, LAYER=3, FORM=3, POS=88900 / 85600, SIZE=16000, DRILL=8000, VIA=true, ROTATION=4500;
PAD, LAYER=3, FORM=1, POS=88900 / 85600, SIZE=16000, DRILL=8000,PAD_ID=12,CON0=14,CON1=25,CON3=7, NAME=|ground|;

Special Commands

There are some optional commands for the creation of  Components or Groups .




Components

The following commands can be used for the creation of Components:



BEGIN_COMPONENT


Necessary parameters

BEGIN_COMPONENT

Defines the beginning of a component.

All following elements till END_COMPONENT will be assigned to this component.



Optional parameters

COMMENT=|aComment|

Defines the comment-text for this component, see also Create a Component

The text must be framed with the pipe character "|" (ASCII 124)

USE_PICKPLACE=false        

Defines if the component uses Pick+Place Data, default=false

See also Pick+Place Data

PACKAGE=|aPackage|

Defines the package-text für this component, see also Pick+Place Data

The text must be framed with the pipe character "|" (ASCII 124)

ROTATION=0

Defines the rotation of the component (in degree), default=0

See also Pick+Place Data



ID_TEXT (Text-label for the Identifier)


Necessary parameters

ID_TEXT

Defines the text-label for the Identifier of the component.

ID_TEXT must be defined in the component.

This text-label can be hide with the option VISIBLE=false in need.

. . .

All other necessary parameters are based on the TEXT command



Optional parameters

VISIBLE=true

Defines if the text-label will be visible or not, default=true

. . .

All other optional parameters are based on the TEXT command



VALUE_TEXT (Text-label for the Value)


Necessary parameters

VALUE_TEXT

Defines the text-label for the Value of the component.

VALUE_TEXT must be defined in the component.

This text-label can be hide with the option VISIBLE=false in need.

. . .

All other necessary parameters are based on the TEXT command



Optional parameters

VISIBLE=true

Defines if the text-label will be visible or not, default=true

. . .

All other optional parameters are based on the TEXT command



END_COMPONENT


Necessary parameters

END_COMPONENT

Defines the end of a component.




Example:

BEGIN_COMPONENT;
  ID_TEXT,LAYER=2,POS=408300/370050,HEIGHT=13000,THICKNESS=2,TEXT=|R1|;
  VALUE_TEXT,VISIBLE=false,LAYER=2,POS=395600/389550,HEIGHT=13000,THICKNESS=2,TEXT=|1k|;
  TRACK,LAYER=2,WIDTH=1500,P0=419100/434800,P1=419100/396800,P2=510500/396800,P3=510500/434800,P4=419100/434800;
  TRACK,LAYER=2,WIDTH=1500,P0=504200/396800,P1=504200/434800;
  PAD,LAYER=3,POS=406400/415800,FORM=1,SIZE=21600,DRILL=8800;
  PAD,LAYER=3,POS=523200/415800,FORM=1,SIZE=21600,DRILL=8800;
END_COMPONENT;





Groups

The following commands can be used for the creation of Groups:



GROUP


Necessary parameters

GROUP

Defines the beginning of a group.

All following elements till END_GROUP will be assigned to this group.



END_GROUP


Necessary parameters

END_GROUP

Defines the end of a group.




Example:

GROUP;
  PAD,LAYER=3,POS=482600/187200,FORM=1,SIZE=21600,DRILL=8800;
  PAD,LAYER=3,POS=508000/174500,FORM=1,SIZE=21600,DRILL=8800;
END_GROUP;

GROUP;
  GROUP;
     PAD,LAYER=3,POS=482600/187200,FORM=1,SIZE=21600,DRILL=8800;
     PAD,LAYER=3,POS=508000/174500,FORM=1,SIZE=21600,DRILL=8800;
  END_GROUP;
  GROUP;
     PAD,LAYER=3,POS=558800/250700,FORM=1,SIZE=21600,DRILL=8800;
     PAD,LAYER=3,POS=584200/263400,FORM=1,SIZE=21600,DRILL=8800;
  END_GROUP;
  PAD,LAYER=3,POS=647700/123700,FORM=1,SIZE=21600,DRILL=8800;
  PAD,LAYER=3,POS=647700/161800,FORM=1,SIZE=21600,DRILL=8800;
END_GROUP;
